# TOOLCHAIN

## Setup tool

The provided `setup_tools.sh` can be run to download and install all the needed tools. Except for the Quartus tools that need to be manually downloaded and installed.

## Quartus

### Quartus Prime Lite
To install Quartus Prime Lite v24.1 please follow the provided link download and install [link](https://www.altera.com/downloads/fpga-development-tools/quartus-prime-lite-edition-design-software-version-24-1-linux).

### SoC FPGA Embedded Development Suite
To install SoC EDS v20.1 please follow the provided link download and install [link](https://www.altera.com/downloads/embedded-tools/soc-fpga-embedded-development-suite-soc-eds-standard-edition-software-version-20-1-linux).
